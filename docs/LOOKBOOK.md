# Deterministic dual-column lookbooks

[简体中文](LOOKBOOK.zh-CN.md) · [Home](../README.md)

The user-selected default presentation is **lookbook_card_v1**, a 1200 × 1800 PNG: one full-height subject image on the left, with a right-hand product/hairstyle information panel. All item images, identifiers, text and arrangement are drawn by Go using the local SQLite archive — **never generated by the image model**.

## Pipeline

~~~text
Choose a saved Look (real product IDs)
          +
One independent full-body image (external or user-supplied)
          +
Go deterministic compositor (shared by Web UI and MCP)
          |
1200×1800 PNG
          |
Manual identity / posture / garment validation
~~~

The compositor does not generate a new face or put clothes on the subject. Passing an AI-generated subject image never proves the subject is the user.

## Local Web UI

Open http://127.0.0.1:17936/lookbook.html from the running Wardrobe instance.

1. Select a saved Look or choose individual outerwear, inner/midlayer, trousers and shoes from archived SQLite records; optionally select a hairstyle reference.
2. Provide **one** JPEG/PNG full-body image, or choose a saved Look that already has an archived portrait photograph.
3. Generate the preview with the Go compositor; missing SKU photos and invalid IDs fail closed.
4. Download the completed 1200 × 1800 PNG; inspect the subject's full head-to-foot framing, facial likeness, garment structure and lack of extra accessories.

The chosen browser image is transmitted only to the **local** Go server through POST /api/lookbook/render; it is not sent to Adobe, Runway or GitHub by this page.

## MCP

Call compose_wardrobe_lookbook with lookId and portraitLookId or portraitImageBase64. The tool returns the finished PNG directly. Cloud-connected MCP clients process the submitted image in their respective AI environment; **this is not the same as local-only Web UI usage**. The output is not automatically archived as an authentic real-world fitting.

## Guarantees vs limitations

| Deterministically guaranteed | Still requires human verification |
| --- | --- |
| Fixed dimensions, columns, order and text layout | Identity/face consistency of external subject image |
| Actual product names, color, size and SKU photos from SQLite | Whether the subject is wearing those exact items |
| No unselected product drawn in the right-hand panel | Subject's pose or unselected objects in the subject photo |
| Missing archived item image fails | Any external image model's compliance |

The current template supports outerwear, a midlayer/inner layer, trousers and shoes. Other items are not implicitly added; changing the template requires updating Go code and tests. See [Try-on](TRYON.md) and [MCP](MCP.md).
